- EVM chains: Supported
- Non-EVM chains: Supported
- Custom Token: N/A
- Native Converter: N/A
- Bridged USDC Standard: N/A
- Wrapped Token: Available
- Manual Converter: Coming soon (EVM chains), Possible (Non-EVM chains)
